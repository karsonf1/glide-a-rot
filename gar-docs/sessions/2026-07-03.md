# GAR Session 2026-07-03

The biggest architectural session on [Glide-A-Rot](../_index.md) so far. Started as segment cleanup and turned into ripping out and replacing the whole procgen approach.

## Shipped

**Forest_A converted to the treadmill convention.** Re-oriented to identity so the 500-stud floor runs along world +Z (it was yawed −90°), anchored all 412 parts, and set the model pivot to the entry (−Z) face at floor-top height. Written up as [Segment Authoring Convention](../decisions/2026-07-03-segment-authoring-convention.md).

**ServerStorage template actually populated.** `ServerStorage.SegmentTemplates.Forest.Forest_A` now holds the full authored geometry — 255 geometry children, 412 parts. It had been **floor-only**, meaning every run would have generated an empty floor with nothing on it. Silent and severe.

**`RunCorridorOrigin` marker added** at `(0, 100, 0)` — anchored, transparent, non-colliding — so ProcGen stops falling back to its hardcoded default.

**Spawn aligned to the corridor.** `SpawnLocation` moved to `(0, 103, −12)` facing +Z, and the Workspace Forest_A authoring copy re-pivoted to `(0, 100, 0)` so the track visually starts just ahead of spawn.

**Flight forward-lock tuned.** In `Client.client.lua`: `MaxYawDeviation` 75 → 90 (full lateral steering, `Vz` reaching 0) and `currentVelZ` floored at 0 — a hard invariant that the glider never travels backward down the corridor away from the rings.

**ProcGen rewritten as a forward streamer** (commit `743fa55`). The full reasoning is in [Forward Streamer over Treadmill](../decisions/2026-07-03-forward-streamer-over-treadmill.md). Short version: the teleport-recycle was setting `hrp.CFrame` server-side on a client-owned part, and the resulting ownership fight was the stutter. Removed the teleport entirely, switched to load-ahead/cull-behind, integrated canyon-wall streaming.

**Incidental critical fix.** `GliderHandler` used `FuelDepleted:Connect`, which is invalid on a BindableEvent — it errored on every load and silently broke the fuel-depletion → `RunEnded` → crate chain. Now `FuelDepleted.Event:Connect`. This had been broken and undetected.

## Decisions made

- [Segment Authoring Convention](../decisions/2026-07-03-segment-authoring-convention.md) — +Z, identity orientation, entry-face pivot, all anchored
- [Forward Streamer over Treadmill](../decisions/2026-07-03-forward-streamer-over-treadmill.md) — no teleport, floor-based alignment, coplanar sections
- Side terrain must be Parts/MeshParts, never voxel Terrain
- Flight steering policy: ±90° lateral cap, never reverse
